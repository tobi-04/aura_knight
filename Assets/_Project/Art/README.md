# Art pipeline

Gameplay art (Leo, enemies, bosses, tilesets, backgrounds) is **generated by scripts**, then imported by one editor step.
Licences: see `LICENSES.md` (repo is public: CC0 or project-owned only).

## Rebuild everything

```bash
python3 -m venv tools/art/.venv && tools/art/.venv/bin/pip install -r tools/art/requirements.txt   # once
tools/art/fetch_sources.sh                          # downloads the CC0 Kenney pack into tools/art/.cache (git-ignored)
tools/art/.venv/bin/python tools/art/build_art.py   # writes PNG sheets + JSON manifests into Assets/_Project/Art
tools/unity-batch.sh exec AuraKnight.Editor.ArtPipeline.GenerateAll   # or menu Aura > Art > Generate All
```

`GenerateAll` is idempotent: preset, Pixel32 settings, slicing, clips, controllers, Rule Tiles, atlases, material. Sprite and clip
GUIDs are reused on re-run, so prefab references survive.

## Conventions

| Item | Rule |
|------|------|
| Grid | 16 px logical, drawn x2: tiles 32 px, PPU 32 (`Pixel32Importer`: Point, Uncompressed, no mipmaps, Full Rect) |
| Cells | Leo and NightKnight 64x64 px; other enemies 48x48; bosses RootTree 96x96, GiantStoneSpider 128x96, RogueMachine 128x128, Malakor 96x128 |
| Pivot | Centre (0.5, 0.5) for every character sheet; feet touch the bottom row of the cell |
| Facing | All sprites face right. Flip by `localScale.x` (see `PlayerAnimatorBridge`) |
| Sprite names | `<Sheet>_<Clip>_<Frame>`, e.g. `Leo_Run_3`; tiles `<Region>_<Ground|Wall|Platform|Spikes>_<Part>` |
| Material | `Materials/Mat_SpriteLit.mat` (URP 2D Sprite-Lit-Default). Light2D lights it; tint with a MaterialPropertyBlock `_Color` (AuraVisuals) |
| Scenes | A lit scene needs a Global Light 2D (GDD 10 intensities per region), otherwise only point lights show lit sprites |

## Adding or changing art

1. New sprite from a generator: edit the script in `tools/art/`, rebuild, rerun `GenerateAll`.
2. Hand-drawn or third-party PNG: drop it under `Characters/Enemies/Bosses/Tilesets/Backgrounds`. New textures there get the
   Pixel32 settings automatically (`Pixel32Postprocessor`). Anywhere else, apply `Presets/Sprite_Pixel32.preset`. Add a row to `LICENSES.md`
   (CC0 only) before committing.
3. Animated sheets need `<Name>.sheet.json` next to the PNG (cell size, pivot, rows: name, frames, fps, loop); see any generated one.
4. New region or variant: add its name to `ArtPaths.cs` and the generator list.

## Using the art

- **Leo**: `Prefabs/Player` visual has the Animator with `Characters/Leo/Leo.controller`; `PlayerAnimatorBridge` feeds the parameters.
- **Enemies/bosses**: give the Animator `Enemies/_Base/EnemyBase.controller` semantics via the variant's
  `<Variant>.overrideController`. See `Enemies/README.md` and `Bosses/README.md` for parameters and clips.
- **Tilemaps**: assign `Tilesets/<Region>/Rules/Tile_<Region>_<Kind>.asset` in the palette. Ground and Wall use Grid colliders;
  Platform needs a PlatformEffector2D / one-way setup on its Tilemap, Spikes a Hazard layer (set by the scene that owns the tilemap).
- **Parallax** (`Backgrounds/<Region>/<Region>_{Bg,Mid,Back,Fg}.png`): speeds 0.1, 0.5, 1.0 (decor behind the action), 1.2; each layer
  tiles horizontally (wrap mode Repeat; use a SpriteRenderer in Tiled draw mode or two copies).
- **Atlases**: `Atlases/Atlas_Player` and one per region (tileset + that region's enemies and boss). Atlas packing is on at build time.
