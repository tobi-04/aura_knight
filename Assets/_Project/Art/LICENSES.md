# Art licences

This repository is public, so **only CC0 or project-owned art is allowed**. Every file under `Characters/`, `Enemies/`, `Bosses/`,
`Tilesets/`, `Backgrounds/` is listed here (UI, Fonts and KeyArt are tracked by the UI work).

## Third-party (CC0)

| Pack | Author | URL | Licence | Verified | Used for |
|------|--------|-----|---------|----------|----------|
| Tiny Dungeon (1.0) | Kenney (kenney.nl) | https://kenney.nl/assets/tiny-dungeon | CC0 1.0 (Creative Commons Zero) | The pack's `License.txt` and the asset page both state CC0; `tools/art/fetch_sources.sh` refuses to continue if `License.txt` lacks "CC0" | Base sprites for `Enemies/Bat`, `Enemies/Ghost`, `Enemies/StoneSpider` (tiles bat, ghost, spider from `tilemap_packed.png`), upscaled x2 with nearest neighbour, outline recoloured, stone-grey recolour for the spider, new animation frames made by script |

Evaluated and **not used** (so nothing from them is in the repo): Kenney Pixel Platformer, Pixel Platformer Industrial Expansion
(18 px tiles, would break the 32 px / PPU 32 density), Kenney Roguelike Caves & Dungeons, Tiny Town. OpenGameArt packs were
not needed: no CC0 pack there covered a knight with the full animation list, and mixing styles was the larger risk (GDD 10).

## Generated, project-owned

Drawn by scripts in `tools/art/` (Python + Pillow; rerun `python3 tools/art/build_art.py`). No third-party pixels except the Kenney
tiles above. All sprites are drawn on a 16 px logical grid and scaled x2, so every sprite shows 2x2 pixel blocks at PPU 32.

| Folder | Content | Source script | Licence |
|--------|---------|---------------|---------|
| `Characters/Leo` | Leo sheet 64x64 cells, 16 clips (palette per GDD: brown hair, armour #1B2233, gold #C99A3B, green scarf, sun shield) | `gen_leo.py` | generated, project-owned |
| `Enemies/NightKnight` | Leo's rig with a dark palette | `gen_enemies.py` (uses `gen_leo.py`) | generated, project-owned |
| `Enemies/ThornBug`, `MushroomHopper`, `PatrolRobot`, `ScrapZapper` | Drawn from scratch | `gen_enemies.py` | generated, project-owned |
| `Enemies/Bat`, `Ghost`, `StoneSpider` | Kenney Tiny Dungeon base, animated and recoloured by script | `gen_enemies.py` | CC0 base (Kenney) + generated, project-owned changes |
| `Bosses/RootTree`, `GiantStoneSpider`, `RogueMachine`, `Malakor` | Drawn from scratch | `gen_bosses.py`, `gen_boss_*.py` | generated, project-owned |
| `Tilesets/<Region>` (Hub, Forest, Cave, City, Castle) | 3x3 ground and wall, platform, spikes | `gen_tilesets.py` | generated, project-owned |
| `Backgrounds/<Region>` | 4 parallax layers each (Bg, Mid, Back, Fg), 640x360, tile horizontally | `gen_backgrounds.py` | generated, project-owned |
| `Presets/Sprite_Pixel32_Template.png` | 4x4 white square used to author the import preset | `Pixel32Importer.cs` | generated, project-owned |

Key art (`docs/reference/NỀN TẢNG Mobile.pdf`) is project-owned concept art; it is not used in gameplay sprites.

## Not art-licensed files

Unity assets in `Art/` that are not images (`*.controller`, `*.overrideController`, `*.anim`, `*.asset` Rule Tiles,
`*.spriteatlasv2`, `*.mat`, `*.preset`) are generated by `Scripts/Editor/Art/` and belong to the project.
