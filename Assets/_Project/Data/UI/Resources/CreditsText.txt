GENERATED, PROJECT-OWNED

Drawn by scripts in tools/art/ (Python + Pillow; rerun python3 tools/art/build_art.py). No third-party pixels except the Kenney
tiles above. All sprites are drawn on a 16 px logical grid and scaled x2, so every sprite shows 2x2 pixel blocks at PPU 32.

WHY GENERATED

OpenGameArt was searched for CC0 chiptune loops, but the game needs five region tracks that each come as two layers with
identical tempo, length and chords (Explore / Combat crossfade in sync). Existing CC0 packs do not ship matching stems, so the
music is generated to that spec instead of mixing unrelated tracks.

ADDING THIRD-PARTY AUDIO LATER

Add one row per source with title, author, URL and license (CC0 only while the repository is public; CC-BY needs the author
credited here and in the credits screen). Check the license on the source page, not the listing.

REGENERATING

bash
python3 tools/audio/generate_sfx.py   # Assets/_Project/Audio/SFX/*.wav
python3 tools/audio/generate_bgm.py   # Assets/_Project/Audio/BGM/*.ogg
tools/unity-batch.sh exec AuraKnight.Editor.AudioAssetGenerator.GenerateAll
