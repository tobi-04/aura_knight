# Audio licenses and sources

The repository is public, so only CC0 or project-owned audio is allowed. Every file here is generated by the scripts in
`tools/audio/` (numpy + ffmpeg, fixed random seeds, so a rerun produces identical files). Nothing was downloaded.

| Files | Title | Author | URL | License |
|-------|-------|--------|-----|---------|
| `SFX/*.wav` (27 files: footsteps, jump, land, dash, slide, wall slide, sword swing / hit, player hurt / die, Aura switch x3, Aura unlock, skills x3, coin, chest, altar, UI tap / back, boss roar, enemy hit / die, respawn) | Aura Knight SFX set | Aura Knight project (`tools/audio/generate_sfx.py`) | n/a (in this repository) | generated, project-owned |
| `BGM/{hub,forest,cave,city,castle}_{explore,combat}.ogg` | Aura Knight region themes (2 synced layers each) | Aura Knight project (`tools/audio/generate_bgm.py`) | n/a (in this repository) | generated, project-owned |
| `BGM/boss_explore.ogg`, `BGM/ending_explore.ogg` | Aura Knight boss theme, ending theme | Aura Knight project (`tools/audio/generate_bgm.py`) | n/a (in this repository) | generated, project-owned |

## Why generated

OpenGameArt was searched for CC0 chiptune loops, but the game needs five region tracks that each come as two layers with
identical tempo, length and chords (Explore / Combat crossfade in sync). Existing CC0 packs do not ship matching stems, so the
music is generated to that spec instead of mixing unrelated tracks.

## Adding third-party audio later

Add one row per source with title, author, URL and license (CC0 only while the repository is public; CC-BY needs the author
credited here and in the credits screen). Check the license on the source page, not the listing.

## Regenerating

```bash
python3 tools/audio/generate_sfx.py   # Assets/_Project/Audio/SFX/*.wav
python3 tools/audio/generate_bgm.py   # Assets/_Project/Audio/BGM/*.ogg
tools/unity-batch.sh exec AuraKnight.Editor.AudioAssetGenerator.GenerateAll
```
