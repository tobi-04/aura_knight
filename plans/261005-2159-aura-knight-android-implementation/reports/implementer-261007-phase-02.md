## Packs and licences
- Only third-party pack used: Kenney Tiny Dungeon 1.0, CC0 (https://kenney.nl/assets/tiny-dungeon; License.txt and page verified, fetch script refuses non-CC0). Used for Bat, Ghost, StoneSpider base tiles (x2 nearest, recoloured, animated by script).

## Generated art (all drawn at 16 px logical, scaled x2, PPU 32)
- Leo: 64x64 cells, 16 clips (Idle, Run, Jump, Fall, Attack1, Attack2, AttackUp, AirAttack, AirAttackUp, AirAttackDown, Dash, Slide, WallSlide, Hurt, Death, Swim). Brown hair, armour #1B2233, gold #C99A3B, green scarf, sun shield.
- 8 enemies, 4 bosses (sizes in Art/README.md), 5 tilesets (Hub, Forest, Cave, City, Castle), 20 parallax layers (4 per region, 640x360, tile horizontally). Art folder size: 3.6 MB.

## Pipeline (Scripts/Editor/Art, asmdef AuraKnight.Editor.Art)
- `AuraKnight.Editor.ArtPipeline.GenerateAll` (menu Aura/Art/Generate All): Sprite_Pixel32.preset + postprocessor for new textures, slicing from JSON manifests (stable sprite IDs), clips, Leo.controller, EnemyBase/BossBase controllers + per-variant override controllers, Rule Tiles (Ground, Wall 3x3; Platform L/M/R; Spikes) per region, Sprite Atlas v2 (Player + 5 regions), Mat_SpriteLit (URP 2D Sprite-Lit-Default).
- Rebuild: tools/art/fetch_sources.sh, python tools/art/build_art.py, then the exec above. Docs in Art/README.md, Enemies/README.md, Bosses/README.md.
- Player wiring: Player prefab visual now uses Leo_Idle_0, Animator with Leo.controller, Mat_SpriteLit, white vertex colour. PlayerAnimatorBridge adds Swim, Attack, AirAttack, Hurt, Dead (bools) and ComboStep, AimDir (ints, from PlayerCombat). MovementTestSceneGenerator adds a Global Light 2D. GeneratedAssetsTests updated (Animator and lit material now expected).

## Follow-ups
- Visuals not inspected in a running Game view (batch only); art quality is programmer art, expect a polish pass.
- The aura tint multiplies the whole sprite; dark armour tints weakly. A masked trim shader (Mat_PlayerAura) is the proper fix.
- Core and Region scenes have no Global Light 2D: Leo (lit) is only lit by his glow there. World/scene owners should add per-region Global Lights (GDD 10: 0.6/0.25/0.45/0.05).
- Platform tiles need PlatformEffector2D, Spikes a Hazard layer on their Tilemaps (scene owners). Key art export (Art/KeyArt) belongs to the UI agent.
